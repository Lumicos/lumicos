## Before recording

1. Use an isolated installation of the reviewed public commit. Record the commit, model/quantization, runtime and GPU/CPU/RAM in a companion note.
2. Use fresh synthetic chats, memory and documents. Hide usernames, paths, browser accounts, tokens and notifications. Get permission for all visible people/assets.
3. Confirm the intended feature works on that installation. Do not demonstrate a private build while labeling it public.
4. Keep the original logo unchanged. Use Windows' existing recording/screenshot tools; no paid service or new dependency is required.
