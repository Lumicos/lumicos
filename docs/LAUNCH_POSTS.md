## English GitHub / Reddit

**Lumicos: local-first AI on a Windows PC with an RX 6600 8GB**

I'm building Lumicos around an ordinary PC: Ryzen 5 3600, RX 6600 8GB and 32GB RAM. The public source brings together llama.cpp/GGUF chat, editable memory and Microsoft Pattara speech, plus experimental local knowledge, ComfyUI image workflows and background research jobs.

It's an early snapshot, not a polished universal installer. Bigger models can need CPU/RAM offloading; quantization and configuration matter. Existing benchmarks come mainly from my daily build and aren't a public-release certification. Optional web search and downloads use the internet.

I'd welcome source reviews and sanitized hardware reports, especially from Windows users with different GPUs. Feature status and install caveats are documented here: https://github.com/Lumicos/lumicos
