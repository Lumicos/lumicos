# Public feature status

Audit target: public commit `d5b43d6`, 30 October 2026. Paths below refer to this repository, not the developer's installed application. **Available** means public implementation with scoped test evidence; it does not certify a fresh install or every GPU. **Experimental** means implemented but gated, incompletely validated or dependent on external runtimes/models. **Planned** means proposed with no implementation verified here. **Private / Not Included** means no deliverable for that capability in this snapshot.

|---|---|---|

Loader exists; fresh install/inference not run in this audit. |

Candidates require user choice; do not advertise automatic durable memory capture. |
