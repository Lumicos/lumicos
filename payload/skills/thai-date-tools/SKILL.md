ใช้เมื่อผู้ใช้ถามเรื่องวันที่แบบไทย จำนวนวัน หรือวันที่หลังจากผ่านไป n วัน

1. รัน run_python (สคริปต์มีอยู่แล้ว ไม่ต้องเขียนใหม่):
   exec(open("skills/thai-date-tools/script.py", encoding="utf-8").read())
   print(to_thai_date("2026-10-22"))               # 22 ตุลาคม 2569
   print(days_between("2026-10-22", "2026-12-31")) # 70
   print(add_days("2026-10-22", 45))               # 2026-12-06
2. ฟังก์ชันรับวันที่ ค.ศ. แบบ YYYY-MM-DD ถ้าผู้ใช้ให้ปี พ.ศ. ให้ลบ 543 ก่อน
3. "วันนี้" ให้ใช้ datetime.date.today().isoformat() ใน run_python เดียวกัน อย่าเดาวันที่เอง
4. days_between นับระยะห่างโดยไม่นับวันแรก ถ้าผู้ใช้อยากนับรวมทั้งวันแรกและวันสุดท้าย ให้บวก 1 และบอกผู้ใช้
