ใช้เมื่อผู้ใช้ให้คิดเปอร์เซ็นต์จากตัวเลขที่ให้มา

1. รัน run_python (สคริปต์มีอยู่แล้ว ไม่ต้องเขียนใหม่):
   exec(open("skills/percent-calc/script.py", encoding="utf-8").read())
   print(percent_of(12.5, 840))       # 12.5% ของ 840 → result 105.0
   print(what_percent(45, 180))       # 45 เป็นกี่ % ของ 180 → 25.0
   print(percent_change(80, 92))      # จาก 80 เป็น 92 → เพิ่มขึ้น 15.0%
   print(add_percent(1200, 8))        # 1,200 บวกอีก 8% → 1296.0 (ลด 8% ใส่ -8)
   print(before_percent(550, 10))     # หลังขึ้น 10% ได้ 550 เดิมคือ 500.0
2. ใส่ตัวเลขตามที่ผู้ใช้พิมพ์ (17.5 ไม่ใช่ 0.175) สคริปต์หาร 100 ให้เอง ห้ามคูณเปอร์เซ็นต์เองในโค้ด
3. ตอบด้วยตัวเลขจากผลของสคริปต์ (ทศนิยมไม่เกิน 2 ตำแหน่ง มีลูกน้ำหลักพัน) ห้ามคิดเลขเองในหัว
